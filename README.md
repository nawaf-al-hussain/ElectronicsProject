# ElectronicsProject

Central repository for the **Electronics project** — storing all research, reports, and related documents, and hosting any apps or websites developed for the project.

**Current phase: project selection (not yet finalized).** The leading candidate is *CropGuard AI* (modular multi-operation agricultural robot); see [`selection/project-selection-brief.md`](selection/project-selection-brief.md) for the verified judging rubric, the Summer '26 competition scan, and the decision gates.

## Repository Structure

| Folder | Purpose |
|--------|---------|
| `selection/` | Project-selection phase: official judging rubric + video/viva guidelines, teacher's problem menu, competition scan, decision brief |
| `research/` | Candidate deep-dives: priced BOM, fourth-operation analysis, motor/power budget, winning strategy |
| `reports/` | Formal reports, progress updates, and final project documentation |
| `docs/` | Supporting documents: CropGuard dossier (docx + digest), project context |
| `apps/` | Future apps and websites developed for the project |

## How This Repo Is Used

- All research and reports produced during the project are committed here, organized by topic and date.
- Documents are written in Markdown (`.md`) so they are readable directly on GitHub.
- Official course/committee documents are kept verbatim under `selection/sources/`; readable text extractions live under `selection/extracted/`.
- The raw Summer '26 registration sheet is deliberately **not** committed — it contains other students' emails, phone numbers and student IDs. Only the sanitized scan (`selection/competition-scan-summer26.md`) is published.
- Any web app or website for the project will live under `apps/`, each in its own subfolder.
